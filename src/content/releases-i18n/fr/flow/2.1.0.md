Rien dans cette version ne change la façon dont un fichier de flux est lu ou écrit, donc un `flows.json` qui tournait sur la 2.0.5 tourne sur la 2.1.0. La mise à jour est un simple changement d'image. Le premier démarrage crée `sessions.json`, `audit.log` et un répertoire `deployments` dans le répertoire de données, et tout le monde se connecte une fois, parce que les sessions vivaient auparavant en mémoire.

Le verrouillage est actif par défaut : cinq échecs pour un compte depuis une adresse, ou vingt depuis une adresse, le verrouillent pendant quinze minutes. `auth.lockout` change les chiffres.

Les notes complètes, avec chaque nouveau réglage, sont sur [la version GitHub](https://github.com/HotLoop-io/hotloop-flow/releases/tag/v2.1.0).

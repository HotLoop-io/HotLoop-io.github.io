Depuis la 2.1.0, c'est une simple mise à jour d'image, sans migration ni indicateur, et un flows.json qui tournait sur la 2.1.0 tourne sur la 2.2.0. Le premier démarrage crée le fichier d'état dans le répertoire de données. Revenir à la 2.1.0 le laisse en place, car la 2.1.0 n'a aucun code qui le lise. Chaque écriture dans ce fichier est une écriture sur une carte SD ou un SSD, donc les changements de contexte sont regroupés et un arrêt brutal peut en perdre jusqu'à 30 secondes.

Les notes complètes, avec chaque nouveau réglage, sont sur [la version GitHub](https://github.com/HotLoop-io/hotloop-flow/releases/tag/v2.2.0).

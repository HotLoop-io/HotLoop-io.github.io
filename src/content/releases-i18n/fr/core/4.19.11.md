Il n'y a aucune migration, et le seul changement d'API est une nouvelle route.

Cette compilation est amd64 uniquement, et la version suivante est un petit incrément de version qui compile les images arm. D'ici là, `stable` garde les images arm qu'il détient. 4.19.10 est la dernière compilation multi-architecture avant celle-ci, et les notes de 4.19.8 listent tout ce qui a changé depuis la précédente.

Les tests ont aussi changé : un test qui attendait la mauvaise lecture sous charge attend maintenant ce qu'il vérifie, le laboratoire de test relance l'émulateur UniFi quand il s'arrête, et le Redpanda du laboratoire a son API d'administration ouverte.

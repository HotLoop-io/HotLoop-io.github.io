Il n'y a aucune migration, et un simple `helm upgrade` ou la mise à jour automatique Quadlet l'applique. La version précédente, 4.19.11, est la dernière dont les écrans par défaut étaient les anciens, et revenir dessus est sans risque, car rien n'a changé dans la base de données.

Cette compilation est amd64 uniquement, et la version suivante est un petit incrément de version qui compile les images arm. D'ici là, `stable` garde les images arm qu'il détient.

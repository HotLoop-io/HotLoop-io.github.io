Un simple `helm upgrade` ou la mise à jour automatique Quadlet la prend en charge.

Une CA qui garantit les certificats clients n'est pas construite, seulement le registre.

Cette compilation est uniquement amd64, et `stable` garde les images arm qu'il détient. La version suivante est un petit changement de version qui compile les images arm.

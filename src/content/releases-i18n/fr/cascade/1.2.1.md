Si vous faites tourner Cascade sur une machine arm64, c'est la version qui la remet à la version actuelle, avec les quatre outils MCP ajoutés par la 1.2.0. Tout le reste est ce que contient la 1.2.0.

Mettez à jour avec `helm upgrade` vers la 1.2.1, ou laissez `:stable` renouveler les unités Quadlet. Rien ne change dans la base de données, donc revenir à la 1.2.0 ou à la 1.1.1 est sans risque.

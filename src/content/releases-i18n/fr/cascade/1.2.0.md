Si vous faites tourner des agents contre Cascade, c'est la version qui ne laisse rien qu'une clé puisse faire sans outil. Tout le reste est ce que contient la 1.1.1 : l'éditeur, le serveur MCP et les écrans.

Mettez à jour avec `helm upgrade` vers la 1.2.0, ou laissez `:stable` renouveler les unités Quadlet. Rien ne change dans la base de données, donc revenir à la 1.1.1 est sans risque. Ce qu'un retour en arrière ne peut pas défaire, c'est ce qu'un agent a déjà fait.

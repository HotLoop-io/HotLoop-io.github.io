Αν τρέχετε το Cascade σε εργοστάσιο, αυτή είναι η κυκλοφορία που αφήνει έναν πράκτορα να το χειρίζεται απ' έξω και έναν άνθρωπο να κάνει από τον επεξεργαστή ό,τι πριν απαιτούσε curl. Η μηχανή, η μορφή του αρχείου workflow και το REST API είναι όπως ήταν στην 1.0.2.

Μερικές διαδρομές δεν είναι εργαλεία σκόπιμα: η δημιουργία κλειδιών API, token SCIM, παρόχων μυστικών και προορισμών αρχείων καταγραφής απαιτεί έναν άνθρωπο συνδεδεμένο, επειδή ένα κλειδί που θα μπορούσε να δημιουργεί κλειδιά είναι ένα διαρρεύσαν κλειδί που κρατά τον εαυτό του ζωντανό. Το `docs/MCP.md` απαριθμεί κάθε εργαλείο και το δικαίωμα πίσω από αυτό.

Αναβαθμίστε με `helm upgrade` στην 1.1.0, ή αφήστε το `:stable` να ανανεώσει τις μονάδες Quadlet. Τίποτε δεν αλλάζει στη βάση δεδομένων, οπότε η επαναφορά στην 1.0.2 είναι ασφαλής. Αυτό που μια επαναφορά δεν μπορεί να αναιρέσει είναι ό,τι έχει ήδη κάνει ένας πράκτορας. Ένα αντίγραφο ασφαλείας πριν από κάθε ενημέρωση παραμένει η σωστή συνήθεια.

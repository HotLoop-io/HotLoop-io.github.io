Αν τρέχετε πράκτορες απέναντι στο Cascade, αυτή είναι η έκδοση που δεν αφήνει τίποτα που μπορεί να κάνει ένα κλειδί χωρίς εργαλείο. Όλα τα υπόλοιπα είναι αυτά που έχει η 1.1.1: ο επεξεργαστής, ο MCP server και οι οθόνες.

Αναβαθμίστε με `helm upgrade` στην 1.2.0, ή αφήστε το `:stable` να ανανεώσει τις μονάδες Quadlet. Δεν αλλάζει τίποτα στη βάση δεδομένων, οπότε η επιστροφή στην 1.1.1 είναι ασφαλής. Αυτό που μια επαναφορά δεν μπορεί να αναιρέσει είναι ό,τι ένας πράκτορας έχει ήδη κάνει.

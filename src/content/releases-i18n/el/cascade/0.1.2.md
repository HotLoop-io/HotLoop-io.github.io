Κατεβάστε το με `podman pull ghcr.io/hotloop-io/hotloop-cascade:0.1.2`, ή εγκαταστήστε το chart με `helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 0.1.2`. Η εικόνα είναι amd64 και arm64, και τα tag είναι 0.1.2, 0.1, 0, latest και stable.

Η αναβάθμιση από την 0.1.1 σημαίνει ότι δεν χρειάζεται να κάνετε τίποτα. Τρέξτε `helm upgrade` στην 0.1.2, ή αφήστε το `:stable` να κυλήσει τις μονάδες Quadlet. Το κλειδί σας και τα workflow σας μένουν εκεί που ήταν.

Η εκτέλεση του tag ήταν η πρώτη φορά που το ghcr.io είδε οτιδήποτε από αυτά.

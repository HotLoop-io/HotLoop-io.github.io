Προσθέστε τη βιβλιοθήκη, δηλώστε ένα function block, προσθέστε τις μεταβλητές που θέλετε να βγουν και καλέστε το μία φορά ανά κύκλο. Οτιδήποτε εγγράφεται στο OPC UA PubSub μπορεί να το διαβάσει, και το HotLoop.

Η βιβλιοθήκη χτίζεται με 0 σφάλματα και 0 προειδοποιήσεις στο CODESYS 3.5.22.30. Ο συνδρομητής του HotLoop core (από τον κύριο κλάδο του core όταν έγινε αυτή η δοκιμή, και στο HotLoop core 4.19.4 και σε κάθε έκδοση μετά) διαβάζει και τους δύο εκδότες, συμπεριλαμβανομένης της συμβολοσειράς, του TIME, και των δύο πινάκων και δύο μετρητών που κινούνται. Ένας δεύτερος αποκωδικοποιητής Go διαβάζει και τα 222 καταγεγραμμένα datagrams. Το μπλοκ προσθέτει κατά μέσο όρο περίπου 10,6 μικροδευτερόλεπτα ανά κύκλο σε μια εργασία 20 ms, ένας κύκλος που στέλνει κοστίζει 10 έως 100, και η μεγαλύτερη αποστολή σε 12 000 κύκλους κράτησε 14,3 ms σε έναν φορτωμένο κοινόχρηστο host, οπότε βάλτε τον εκδότη στη δική του εργασία χαμηλότερης προτεραιότητας αν αυτό έχει σημασία για τη λογική του ελέγχου σας.

Τι δεν εκτελέστηκε: κανένας φυσικός ελεγκτής, κανένα runtime εκτός του Control for Linux SL 4.22.0.0, καμία CPU εκτός του x86-64, multicast, ένα runtime που χάνει και ξανακερδίζει το δίκτυό του, το τέλος του δίωρου παραθύρου επίδειξης, και δέκτες άλλοι από τους τέσσερις παραπάνω.

Όχι σε αυτή την έκδοση: χρονοσφραγίδες, KeepAlive και Delta Frames, περισσότερα από ένα DataSetMessage ανά NetworkMessage, WSTRING, κατάσταση ανά πεδίο, ασφάλεια μηνυμάτων και η πλευρά του συνδρομητή. Ένας δέκτης που επιμένει σε χρονοσφραγίδα, KeepAlive ή Delta Frame δεν θα ικανοποιηθεί από αυτή την έκδοση.

Κατεβάστε το `HotLoopTransmitter-1.0.0.library` από το [hotloop.io/hotloop-transmitter/1.0.0/](https://hotloop.io/hotloop-transmitter/1.0.0/HotLoopTransmitter-1.0.0.library), ελέγξτε το με το `SHA256SUMS` στον ίδιο φάκελο, και εγκαταστήστε το με Tools, Library Repository, Install στο CODESYS 3.5 SP22 ή νεότερο. Το `.compiled-library` είναι η ίδια βιβλιοθήκη χωρίς τον πηγαίο κώδικά της. Η [σελίδα εγκατάστασης](https://docs.hotloop.io/transmitter/install/) έχει τα υπόλοιπα.

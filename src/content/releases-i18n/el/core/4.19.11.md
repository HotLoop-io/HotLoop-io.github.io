Δεν υπάρχουν μετεγκαταστάσεις, και η μόνη αλλαγή στο API είναι μια νέα διαδρομή.

Αυτό το build είναι μόνο amd64, και η επόμενη έκδοση είναι μια μικρή αύξηση έκδοσης που χτίζει τα arm images. Στο μεταξύ το `stable` κρατά τα arm images που έχει. Το 4.19.10 είναι το τελευταίο build πολλαπλών αρχιτεκτονικών πριν από αυτό, και οι σημειώσεις του 4.19.8 απαριθμούν ό,τι άλλαξε από το προηγούμενο.

Άλλαξαν και τα τεστ: ένα που περίμενε τη λάθος ανάγνωση υπό φορτίο τώρα περιμένει αυτό που ελέγχει, το εργαστήριο δοκιμών ξεκινά ξανά τον προσομοιωτή UniFi όταν αυτός τερματίζει, και το Redpanda του εργαστηρίου έχει ανοιχτό το API διαχείρισής του.

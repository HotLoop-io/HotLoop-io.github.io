2.2.0에서는 이미지만 올리면 되고, 마이그레이션도 플래그도 없으며, 2.2.0에서 돌던 flows.json과 설정 파일은 2.3.0에서도 돕니다. 스키마가 어디에도 없는 플로는 이전과 똑같이 동작하고, HotLoop을 고르지 않은 쓰기 노드는 2.2.0에서처럼 씁니다. 새 노드를 쓰지 않는 플로라면 2.2.0으로 돌아가도 안전합니다. HotLoop, MCP, 플러그인 노드는 거기서 시작되지 않으며, HotLoop을 고른 쓰기 노드는 2.2.0에서 장비에 곧바로 쓰므로, 돌아가기 전에 해당 노드에서 HotLoop을 빼 두세요.

MCP는 Flow로 들어오는 새로운 길이며 토큰이 필요합니다. 플로에 mcp tool 노드가 생기기 전에는 아무것도 제공되지 않고, 토큰이 없거나 꾸며낸 토큰으로 한 호출은 거부됩니다. 플러그인은 런타임에 신뢰하는 키를 주기 전까지 꺼져 있으며, 차트는 모든 것을 plugins 아래에 받고 enabled는 기본이 false입니다.

쓰기 노드는 HotLoop의 쓰기 게이트를 통해 보내며, 게이트는 Modbus 쓰기로 처음부터 끝까지 시험했습니다. 스키마 검증기는 Ajv가 아닙니다. 스키마 밖의 $ref는 거부하고 모르는 format 값은 무시합니다. Flow에 이제 Raspberry Pi 5 수치가 있습니다. 새 설정이 모두 담긴 전체 노트는 [GitHub 릴리스](https://github.com/HotLoop-io/hotloop-flow/releases/tag/v2.3.0)에 있습니다.

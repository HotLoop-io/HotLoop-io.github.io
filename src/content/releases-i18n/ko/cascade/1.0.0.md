`podman pull ghcr.io/hotloop-io/hotloop-cascade:1.0.0`으로 받거나, `helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 1.0.0`으로 설치하세요. 이미지는 amd64와 arm64입니다.

1.0.0이라고 부르는 이유는 편집기가 제 이름을 그 숫자 아래에 걸기 전에 원했던 마지막 조각이었기 때문입니다. 아직 워크플로 파일 형식이나 API에 대한 약속은 아니며, 로드맵에는 아직 만들지 않은 것이 적혀 있습니다. Git 소스 관리와 환경, 더 많은 커넥터, AI 단계입니다. 0.1.2의 모든 것은 전과 같이 동작합니다. 롤백은 이전 버전을 되돌려 놓을 뿐 데이터베이스 변경을 되돌리지 않으므로, 업그레이드하기 전에 백업하세요.

변수는 시크릿이 아닙니다. 프로젝트를 읽을 수 있는 사람은 그 변수도 읽습니다. 외부 시크릿에는 허용된 경로가 필요하며, 경로가 하나도 없는 공급자는 의도적으로 거부됩니다. SCIM은 인스턴스 소유자를 공급자에게 절대 보여 주지 않고, DELETE는 계정을 끄고 숨깁니다. SAML, LDAP, OIDC 설정은 시작할 때 환경에서 읽으므로, 로그인 화면은 무엇이 켜져 있는지 보여 줄 뿐 바꾸지 않으며, 로그인 페이지 자체는 여전히 이전의 단순한 페이지입니다.

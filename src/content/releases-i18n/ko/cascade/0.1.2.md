`podman pull ghcr.io/hotloop-io/hotloop-cascade:0.1.2`로 받거나, `helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 0.1.2`로 차트를 설치하세요. 이미지는 amd64와 arm64이고, 태그는 0.1.2, 0.1, 0, latest, stable입니다.

0.1.1에서 올리는 데는 할 일이 없습니다. 0.1.2로 `helm upgrade`를 실행하거나, `:stable`이 Quadlet 유닛을 롤링하게 두세요. 키와 워크플로는 있던 자리에 그대로 있습니다.

태그 실행은 ghcr.io가 이 가운데 무엇이든 처음 본 순간이었습니다.

라이브러리를 추가하고, 펑션 블록 하나를 선언하고, 내보낼 변수를 추가한 뒤, 사이클마다 한 번 호출하세요. OPC UA PubSub를 구독하는 것이면 무엇이든, HotLoop을 포함해 읽을 수 있습니다.

라이브러리는 CODESYS 3.5.22.30에서 오류 0, 경고 0으로 빌드됩니다. HotLoop core의 구독자(이 테스트를 실행했을 때의 core main 브랜치와 HotLoop core 4.19.4 및 이후 모든 릴리스)는 문자열, TIME, 두 배열, 움직이는 두 카운터를 포함해 두 퍼블리셔를 읽습니다. 두 번째 Go 디코더는 캡처한 222개의 데이터그램을 모두 읽습니다. 블록은 20 ms 태스크에서 사이클당 평균 약 10.6마이크로초를 더하고, 전송이 있는 사이클은 10에서 100이 들며, 12000 사이클 중 가장 긴 전송은 바쁜 공유 호스트에서 14.3 ms가 걸렸으므로, 제어 로직에 문제가 된다면 퍼블리셔를 자체의 더 낮은 우선순위 태스크에 두세요.

실행하지 않은 것: 모든 물리 컨트롤러, Control for Linux SL 4.22.0.0 외의 모든 런타임, x86-64 외의 모든 CPU, 멀티캐스트, 네트워크를 잃었다가 되찾는 런타임, 2시간 데모 기간의 끝, 그리고 위의 넷 이외의 수신기.

이번 릴리스에 없는 것: 타임스탬프, KeepAlive와 Delta Frame, NetworkMessage당 둘 이상의 DataSetMessage, WSTRING, 필드별 상태, 메시지 보안, 구독자 쪽. 타임스탬프, KeepAlive, Delta Frame을 고집하는 수신기는 이 버전으로는 만족할 수 없습니다.

`HotLoopTransmitter-1.0.0.library`를 [hotloop.io/hotloop-transmitter/1.0.0/](https://hotloop.io/hotloop-transmitter/1.0.0/HotLoopTransmitter-1.0.0.library)에서 내려받아 같은 폴더의 `SHA256SUMS`로 확인하고, CODESYS 3.5 SP22 이상에서 Tools, Library Repository, Install로 설치하세요. `.compiled-library`는 소스가 없는 같은 라이브러리입니다. 나머지는 [설치 페이지](https://docs.hotloop.io/transmitter/install/)에 있습니다.

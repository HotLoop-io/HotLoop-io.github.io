4.24.0은 HotLoop 화면을 P&ID로 만들고, CODESYS PLC 자체의 알람을 알람 목록으로 가져오며, 잘못 읽히던 두 가지 문제를 닫습니다. 끝나지 않던 스크립트 실행과 읽히지 않던 데이터 볼륨입니다.

## 바뀐 내용

- **화면이 P&ID입니다.** 심볼 페이지에 탱크, 펌프, 밸브, 열교환기, 필터, 계기, 접합부를 놓은 다음 한 연결점에서 다른 연결점으로 끕니다. 배관은 페이지의 모든 것을 피해 스스로 직각으로 놓이고, 다른 배관 위에 놓은 자리에서 접합부로 갈라지며, 심볼을 옮기는 동안 다시 놓입니다. 모든 배관은 색, 코드, 선 무늬를 가진 매체를 나타내므로 색만이 유일한 표시가 되지 않으며, 자기 태그나 규칙과 함께 움직입니다. P&ID는 같은 화면 파일로 저장, 내보내기, 가져오기가 됩니다.
- **모든 심볼 페이지의 보기 컨트롤.** 확대와 축소, 이동, 미니맵, 회색 고성능 보기입니다.
- **CODESYS PLC 자체의 알람이 HotLoop 알람 목록에 표시됩니다.** CODESYS 장치는 PLC의 알람 관리자가 가진 알람을 읽습니다. 활성, 확인 대기, 조건이 아직 유지되는 중에 확인된 알람이며, HotLoop에서 한 확인 응답은 PLC로 돌아갑니다. HotLoop Alarms 라이브러리와 프로젝트의 블록 하나가 필요합니다.
- **박스의 데이터 볼륨이 항상 읽힙니다.** 박스 상태의 `data_util_pct` 태그는 데이터 폴더가 만들어질 볼륨을 읽으므로, `/data` 아래에 아무것도 마운트되지 않은 박스도 더는 불량으로 읽히지 않습니다.
- **스크립트 실행은 항상 끝납니다.** 데이터베이스가 실행 종료 기록을 거부하면 HotLoop이 다시 요청하며, 사이에 짧은 대기를 두고 최대 다섯 번까지 합니다.
- **UniFi Protect, Access, SmartPower PDU 출력이 로드맵에서 제공 완료로 표시됩니다.** 4.23.6에서 장치로 도착했습니다.

## 업그레이드

평범한 `helm upgrade`입니다. 마이그레이션도, 새 시크릿도 없습니다. 배관이 없는 심볼 페이지는 전과 같이 그려집니다. 이번 릴리스는 amd64 이미지를 빌드하며, arm 이미지는 다음 버전에서 따라옵니다.

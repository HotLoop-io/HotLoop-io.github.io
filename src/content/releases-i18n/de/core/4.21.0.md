Ein einfaches `helm upgrade` oder das automatische Quadlet-Update übernimmt es.

Eine CA, die für Client-Zertifikate bürgt, ist nicht gebaut, nur die Registry.

Dieser Build ist nur amd64, und `stable` behält die arm-Images, die es hält. Das nächste Release ist eine kleine Versionserhöhung, die die arm-Images baut.

Wenn Sie Cascade hinter einer Anmeldung betreiben, ist dies das Update, das verhindert, dass ein Schluckauf der Datenbank das ganze Werk abmeldet. Sonst hat sich gegenüber 1.0.0 nichts geändert.

Aktualisieren Sie mit `helm upgrade` auf 1.0.1, oder lassen Sie `:stable` die Quadlet-Units nachziehen. In der Datenbank ändert sich nichts, deshalb ist ein Zurückgehen auf 1.0.0 sicher. Eine Sicherung vor jedem Update bleibt die richtige Gewohnheit.

Wenn Sie Agenten gegen Cascade laufen lassen, ist dies die Version, die nichts übrig lässt, was ein Schlüssel tun darf, ohne dass es ein Werkzeug dafür gibt. Alles andere ist, was 1.1.1 hat: der Editor, der MCP-Server und die Bildschirme.

Aktualisieren Sie mit `helm upgrade` auf 1.2.0 oder lassen Sie `:stable` die Quadlet-Units erneuern. In der Datenbank ändert sich nichts, daher ist das Zurückspielen von 1.1.1 sicher. Was ein Rollback nicht rückgängig machen kann, ist das, was ein Agent schon getan hat.

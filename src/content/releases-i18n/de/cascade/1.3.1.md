Wenn Sie Cascade auf einer arm64-Box betreiben, bringt diese Version sie auf 1.3.0 mit dem Editor in vierzehn Sprachen. Alles andere ist, was 1.3.0 hat.

Aktualisieren Sie mit `helm upgrade` auf 1.3.1 oder lassen Sie `:stable` die Quadlet-Units erneuern. In der Datenbank ändert sich nichts, daher ist das Zurückspielen von 1.3.0 oder 1.2.1 sicher.

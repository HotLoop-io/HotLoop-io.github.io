Laden Sie es mit `podman pull ghcr.io/hotloop-io/hotloop-cascade:0.1.2` oder installieren Sie das Chart mit `helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 0.1.2`. Das Image ist amd64 und arm64, und die Tags sind 0.1.2, 0.1, 0, latest und stable.

Ein Update von 0.1.1 bedeutet, nichts zu tun. Führen Sie `helm upgrade` auf 0.1.2 aus oder lassen Sie `:stable` die Quadlet-Units neu starten. Ihr Schlüssel und Ihre Workflows bleiben, wo sie waren.

Der Tag-Lauf war das erste Mal, dass ghcr.io etwas davon sah.

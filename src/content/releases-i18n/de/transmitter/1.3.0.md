Ein SPS-Projekt, das bereits 1.2.0 nutzt, sendet dieselben Bytes wie zuvor, mit einem sichtbaren Unterschied: Der Zeitstempel hat jetzt Millisekunden. Alles andere schalten Sie mit einem Aufruf oder einem Eingang ein.

Installieren Sie `HotLoopTransmitter-1.3.0.library` (oder öffnen Sie das `.package` mit dem CODESYS Installer), ändern Sie die Bibliotheksversion im Library Manager Ihres Projekts auf 1.3.0.0 und kompilieren Sie. HotLoop Alarms 1.0.0.0 liegt unverändert bei, und ein auf 1.2.0 festgelegtes Projekt läuft weiter.

Laden Sie `HotLoopTransmitter-1.3.0.library`, das `.compiled-library` oder das `.package` sowie `HotLoopAlarms-1.0.0.0.library` oder dessen `.compiled-library` von [hotloop.io/hotloop-transmitter/1.3.0/](https://hotloop.io/hotloop-transmitter/1.3.0/HotLoopTransmitter-1.3.0.library) herunter, prüfen Sie sie mit `SHA256SUMS` im selben Ordner und lesen Sie die [Installationsseite](https://docs.hotloop.io/transmitter/install/).

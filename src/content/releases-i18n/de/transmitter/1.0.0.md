Fügen Sie die Bibliothek hinzu, deklarieren Sie einen Funktionsbaustein, fügen Sie die Variablen hinzu, die hinaus sollen, und rufen Sie ihn einmal pro Zyklus auf. Alles, was OPC UA PubSub abonniert, kann ihn lesen, HotLoop eingeschlossen.

Die Bibliothek baut in CODESYS 3.5.22.30 mit 0 Fehlern und 0 Warnungen. Der Subscriber von HotLoop core (aus dem Hauptzweig von core zum Zeitpunkt dieses Tests sowie in HotLoop core 4.19.4 und jedem späteren Release) liest beide Publisher, einschließlich des Strings, des TIME, beider Arrays und zweier Zähler, die sich bewegen. Ein zweiter Go-Decoder liest alle 222 aufgezeichneten Datagramme. Der Block fügt bei einer 20-ms-Task im Mittel etwa 10,6 Mikrosekunden pro Zyklus hinzu, ein Zyklus, der sendet, kostet 10 bis 100, und das längste Senden in 12 000 Zyklen dauerte auf einem ausgelasteten gemeinsamen Host 14,3 ms. Legen Sie den Publisher daher in eine eigene Task niedrigerer Priorität, wenn das für Ihre Steuerungslogik wichtig ist.

Nicht ausgeführt wurden: jede physische Steuerung, jede Runtime außer Control for Linux SL 4.22.0.0, jede CPU außer x86-64, Multicast, eine Runtime, die ihr Netzwerk verliert und wiedererlangt, das Ende des zweistündigen Demo-Fensters und andere Empfänger als die vier oben.

Nicht in diesem Release: Zeitstempel, KeepAlive und Delta Frames, mehr als eine DataSetMessage pro NetworkMessage, WSTRING, ein Status pro Feld, Nachrichtensicherheit und die Subscriber-Seite. Ein Empfänger, der auf einem Zeitstempel, einem KeepAlive oder einem Delta Frame besteht, wird von dieser Version nicht zufriedengestellt.

Laden Sie `HotLoopTransmitter-1.0.0.library` von [hotloop.io/hotloop-transmitter/1.0.0/](https://hotloop.io/hotloop-transmitter/1.0.0/HotLoopTransmitter-1.0.0.library) herunter, prüfen Sie sie mit `SHA256SUMS` im selben Ordner und installieren Sie sie mit Tools, Library Repository, Install in CODESYS 3.5 SP22 oder neuer. Die `.compiled-library` ist dieselbe Bibliothek ohne ihren Quellcode. Die [Installationsseite](https://docs.hotloop.io/transmitter/install/) enthält den Rest.

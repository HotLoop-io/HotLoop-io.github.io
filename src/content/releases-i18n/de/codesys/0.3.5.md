0.3.5 steht im Index unter hotloop.io/hotloop-codesys/, veröffentlicht am 2026-11-16. Die Lizenzannotation des Charts ist die EmberNet Source License 1.0. Charts nach 0.3.5 stehen unter der HotLoop Source License Agreement 1.0, von der HotLoop LLC.

Der Provisioner erreichte die Runtime auf 4840 und wurde als anonymer Benutzer abgewiesen, so wie diese Runtime eingerichtet ist, daher blieb sein eigenes Gerät ausstehend, und das Listener-Gerät und seine Tags wurden angelegt, genau wie bei 0.3.4.

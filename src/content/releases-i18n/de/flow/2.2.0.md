Ab 2.1.0 ist es ein einfaches Image-Update, ohne Migration und ohne Flag, und eine flows.json, die auf 2.1.0 lief, läuft auf 2.2.0. Der erste Start legt die Zustandsdatei im Datenverzeichnis an. Der Weg zurück auf 2.1.0 lässt sie, wo sie ist, weil 2.1.0 keinen Code hat, der sie liest. Jeder Schreibvorgang in diese Datei ist ein Schreibvorgang auf eine SD-Karte oder eine SSD, deshalb werden Kontextänderungen gebündelt, und ein harter Abbruch kann bis zu 30 Sekunden davon verlieren.

Die vollständigen Hinweise mit jeder neuen Einstellung stehen im [GitHub-Release](https://github.com/HotLoop-io/hotloop-flow/releases/tag/v2.2.0).

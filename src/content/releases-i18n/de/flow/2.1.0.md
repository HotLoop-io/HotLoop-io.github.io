Nichts in dieser Version ändert, wie eine Flow-Datei gelesen oder geschrieben wird, daher läuft eine `flows.json`, die auf 2.0.5 lief, auf 2.1.0. Das Update ist ein Image-Wechsel. Der erste Start legt `sessions.json`, `audit.log` und ein Verzeichnis `deployments` im Datenverzeichnis an, und alle melden sich einmal an, weil Sitzungen früher im Arbeitsspeicher lagen.

Die Sperre ist standardmäßig an: Fünf Fehlversuche für ein Konto von einer Adresse oder zwanzig von einer Adresse sperren sie für fünfzehn Minuten. `auth.lockout` ändert die Zahlen.

Die vollständigen Hinweise mit jeder neuen Einstellung stehen im [GitHub-Release](https://github.com/HotLoop-io/hotloop-flow/releases/tag/v2.1.0).

CODESYS プロジェクトがすでに発生させているアラームが HotLoop のアラーム一覧に表示され、HotLoop で1件を確認すると PLC でも確認されます。パブリッシャだけをお使いなら、変更するものはありません。

実際の CODESYS Control for Linux SL 4.22.0.0 ランタイムで実行しました。PLC での発生は HotLoop に表示され、HotLoop での確認は PLC のアラームを時刻付きで確認済みにし、リセットは確認待ちになり、HotLoop での確認で両方が消えます。パブリッシャはラボ全体を再び通過しました。Variant と RawData、タイムスタンプ、open62541、HotLoop 自身のサブスクライバにわたる 128 件のチェックで、`.package` は CODESYS Installer のコマンドラインでインストールできます。

実行していないもの: 物理コントローラ、Control for Linux SL 4.22.0.0 以外のランタイム、確認して確定を求めるクラス以外のアラームクラス、同時に 64 件を超えるアクティブなアラーム。

`HotLoopTransmitter-1.2.0.library`、`.compiled-library`、`.package`、および `HotLoopAlarms-1.0.0.0.library` かその `.compiled-library` を [hotloop.io/hotloop-transmitter/1.2.0/](https://hotloop.io/hotloop-transmitter/1.2.0/HotLoopTransmitter-1.2.0.library) からダウンロードし、同じフォルダの `SHA256SUMS` で確認して、[インストールページ](https://docs.hotloop.io/transmitter/install/)をご覧ください。

ライブラリを追加し、ファンクションブロックを1つ宣言し、出力したい変数を追加して、サイクルごとに1回呼び出します。OPC UA PubSubをサブスクライブするものなら何でも、HotLoopを含めて読み取れます。

ライブラリはCODESYS 3.5.22.30でエラー0、警告0でビルドできます。HotLoop coreのサブスクライバー(このテストを実行した時点のcoreのmainブランチ、およびHotLoop core 4.19.4とそれ以降のすべてのリリース)は、文字列、TIME、両方の配列、動く2つのカウンターを含め、両方のパブリッシャーを読み取ります。2つ目のGoデコーダーは、キャプチャした222個のデータグラムをすべて読み取ります。ブロックは20 msのタスクで1サイクルあたり平均約10.6マイクロ秒を加え、送信するサイクルは10から100かかり、12000サイクル中で最長の送信は、混雑した共有ホスト上で14.3 msかかりました。制御ロジックにとって重要なら、パブリッシャーを専用の、より優先度の低いタスクに入れてください。

実行していないもの:物理コントローラー全般、Control for Linux SL 4.22.0.0以外のランタイム、x86-64以外のCPU、マルチキャスト、ネットワークを失って取り戻すランタイム、2時間のデモ期間の終わり、そして上の4つ以外の受信側。

このリリースに含まれないもの:タイムスタンプ、KeepAliveとDelta Frame、NetworkMessageあたり複数のDataSetMessage、WSTRING、フィールドごとのステータス、メッセージセキュリティ、サブスクライバー側。タイムスタンプ、KeepAlive、Delta Frameを必須とする受信側は、このバージョンでは満たされません。

`HotLoopTransmitter-1.0.0.library`を[hotloop.io/hotloop-transmitter/1.0.0/](https://hotloop.io/hotloop-transmitter/1.0.0/HotLoopTransmitter-1.0.0.library)からダウンロードし、同じフォルダの`SHA256SUMS`で確認し、CODESYS 3.5 SP22以降でTools、Library Repository、Installからインストールしてください。`.compiled-library`は、ソースなしの同じライブラリです。そのほかは[インストールページ](https://docs.hotloop.io/transmitter/install/)にあります。

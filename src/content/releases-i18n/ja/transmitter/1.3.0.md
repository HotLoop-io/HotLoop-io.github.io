すでに 1.2.0 を使っている PLC プロジェクトは、以前と同じバイト列を送ります。目に見える違いは 1 つ、タイムスタンプにミリ秒が付くことです。ほかはすべて、呼び出しか入力で有効にするものです。

`HotLoopTransmitter-1.3.0.library` をインストールし(または CODESYS Installer で `.package` を開き)、プロジェクトの Library Manager でライブラリのバージョンを 1.3.0.0 に変えてコンパイルします。HotLoop Alarms 1.0.0.0 は変更なしで付属し、1.2.0 に固定したプロジェクトもそのまま動きます。

`HotLoopTransmitter-1.3.0.library`、`.compiled-library` または `.package`、および `HotLoopAlarms-1.0.0.0.library` かその `.compiled-library` を [hotloop.io/hotloop-transmitter/1.3.0/](https://hotloop.io/hotloop-transmitter/1.3.0/HotLoopTransmitter-1.3.0.library) からダウンロードし、同じフォルダの `SHA256SUMS` で確認して、[インストールページ](https://docs.hotloop.io/transmitter/install/)をご覧ください。

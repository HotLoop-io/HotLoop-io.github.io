hotloop.io/hotloop-codesys/のインデックスにある最初のchartで、2026-11-05に公開されました。すでに公開されているHotLoop 4.19.4が必要で、同じ日に0.3.1に置き換えられました。インストールするのは0.3.1です。

実行した環境:コンテナ内のCODESYS Control for Linux SL 4.22.0.0ランタイムでHotLoop自身のラボプログラムを実行し、HotLoopのmainブランチからビルドしたHotLoop Edgeイメージを使いました。デバイス、そのタグ、アラーム、画面は手作業なしで現れ、すべての値が良好に読み取られて動き、podを削除してもpodは戻り、インストールはランタイムの再起動中に「the PLC's runtime is not answering」という理由で不良と表示され、約88秒後に自動で復帰しました。

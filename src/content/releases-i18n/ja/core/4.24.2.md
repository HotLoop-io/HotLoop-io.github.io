4.24.2 は 3 種類のデバイスを加え、仕様の求める方法で任意の長さの OPC UA パスワードを送り、エッジの 2 つの問題を直します。低速な回線の先で決して空にならなかった転送キューと、起動しなかった Edge の既定のインストールです。

## 変更点

- **あらゆる世代の Shelly。** Gen2 以降はライブの websocket を使う RPC で、変化とボタン押下が起きた瞬間に届き、Gen1 は独自の HTTP インターフェイスで読み取ります。ボタン押下はデバイスの下のログブックに記録されます。
- **ONVIF カメラ。** ネットワーク上のカメラを見つけ(WS-Discovery)、各デバイスの情報、すべてのメディアプロファイルのストリームとスナップショットのアドレス(Media と Media2)、パン・チルト・ズーム、カメラ自身のイベントをタグとログブックの行として読み取ります。プロファイルの現在の画像は、ルート 1 つで取得できます。
- **Firmata 経由の Arduino。** USB シリアルまたは TCP で、デジタルとアナログのピン、PWM、サーボ、I2C デバイスをタグとして扱います。
- **任意の長さの OPC UA パスワード。** 64 バイトを超えるパスワードが、仕様が求める方法(RsaEncryptedSecret、パート 4、7.40.4)で、クライアントからサーバーへ OPC UA 経由で送られるようになり、古いサーバーも引き続きサインインできます。OPC Foundation 自身のスタックを相手に検証済みです。
- **低速な回線がノードをディスクに縛りつけなくなりました。** ディスクの最後の部分を取り込むパスが、その後ろに入ってくるものをメモリから送るようになったため、低速な回線の先の転送キューは空になり、ノードはポーリングのたびに fsync する代わりにディスクから離れます。
- **HotLoop Edge の既定のインストールが起動します。** Pod は、存在しない Secret からアラームチャンネルの認証情報を読まなくなりました。それぞれは設定されているときだけ送られ、送信先が設定されたチャートはこれまでどおりレンダーされます。

## アップグレード

通常の`helm upgrade`です。移行も新しいシークレットも不要です。このリリースはamd64イメージをビルドし、armイメージは次のバージョンで続きます。

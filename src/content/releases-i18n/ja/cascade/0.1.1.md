`podman pull ghcr.io/hotloop-io/hotloop-cascade:0.1.1`で取得するか、`helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 0.1.1`でチャートをインストールします。イメージはamd64とarm64で、タグは0.1.1、0.1、0、latest、stableです。このリリースではレジストリが非公開だったので、先にrootで`podman login ghcr.io`が必要でした。イメージとチャートは0.1.2から公開され、ログインなしで取得できます。

0.1.0のタグはありましたが、何も公開しませんでした。テストが、古いPodがまだ停止している最中にPodを一覧してアップグレードを確認していたためで、静かなノートパソコンではそれが表に出ません。

移行は前にしか進みません。ロールバックは古いイメージを戻すだけで、データベースの移行は元に戻さないので、更新をオンにする前にバックアップを取ってください。保存した認証情報を封印するキーを失うと、保存した認証情報はすべて読めなくなるので、そのマシン以外の場所にコピーを保管してください。まだないもの: SAML、LDAP、SCIM、環境、リースを使うHAスケジューラー、さらに多くのコネクター、AIのステップ。これらは0.2.0以降です。

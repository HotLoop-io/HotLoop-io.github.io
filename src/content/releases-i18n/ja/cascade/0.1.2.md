`podman pull ghcr.io/hotloop-io/hotloop-cascade:0.1.2`で取得するか、`helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 0.1.2`でチャートをインストールします。イメージはamd64とarm64で、タグは0.1.2、0.1、0、latest、stableです。

0.1.1からのアップグレードでは、することは何もありません。0.1.2へ`helm upgrade`を実行するか、`:stable`にQuadletユニットをロールさせます。キーとワークフローは元の場所にそのままあります。

タグの実行は、ghcr.ioがこの中のどれかを初めて目にした機会でした。

`podman pull ghcr.io/hotloop-io/hotloop-cascade:1.0.0`で取得するか、`helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 1.0.0`でインストールします。イメージはamd64とarm64です。

1.0.0と呼ぶのは、この数字の下に自分の名前を置く前に欲しかった最後の部品が、エディターだったからです。ワークフローのファイル形式やAPIについてはまだ約束ではなく、ロードマップには、まだ作っていないものが書かれています。Gitのソース管理と環境、さらに多くのコネクター、そしてAIのステップです。0.1.2にあったものは、これまでどおり動きます。ロールバックは古いバージョンを戻すだけでデータベースの変更は元に戻さないので、アップグレードの前にバックアップを取ってください。

変数はシークレットではありません。プロジェクトを読める人は、その変数も読めます。外部シークレットには許可されたパスが必要で、パスのないプロバイダーは意図的に拒否されます。SCIMはインスタンスのオーナーをプロバイダーに見せることはなく、DELETEはアカウントをオフにして隠します。SAML、LDAP、OIDCの設定は起動時に環境から読み込まれるので、サインイン画面は何がオンかを表示するだけで変更はせず、サインインページ自体は以前のシンプルなままです。

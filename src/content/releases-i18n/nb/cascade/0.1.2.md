Hent den med `podman pull ghcr.io/hotloop-io/hotloop-cascade:0.1.2`, eller installer chartet med `helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 0.1.2`. Avbildet er amd64 og arm64, og taggene er 0.1.2, 0.1, 0, latest og stable.

Å oppgradere fra 0.1.1 betyr at det ikke er noe å gjøre. Kjør `helm upgrade` til 0.1.2, eller la `:stable` rulle Quadlet-enhetene. Nøkkelen din og workflowene dine blir der de var.

Tagg-kjøringen var første gang ghcr.io så noe av dette.

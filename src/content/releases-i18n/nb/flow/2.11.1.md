HotLoop Flow 2.11.1 er 2.11.0 med arm64-avbildet lagt til, og ingenting annet. 2.11.0 kom bare for amd64 for å nå produksjon først og stå som stabil, og det gjorde den: et anlegg kjørte den med 13 727 noder og uten omstarter. Dette er den lille oppdateringen som bygger begge. Koden, chartet, innstillingene og flytene dine endres ikke.

## Hva som er endret

- Avbildet bygges for linux/amd64 og linux/arm64. Taggene `2.11.1`, `2.11` og `2` har begge.
- README og installasjonssidene nevner 2.11.1 og sier amd64 og arm64. Installasjonslinjen i README i 2.11.0 pekte fortsatt på 2.10.2-avbildet; nå nevner den 2.11.1.

## Oppgradering

En vanlig `helm upgrade` til 2.11.1-avbildet og -chartet, eller den nye taggen i Quadlet-enheten din. Hvis du bruker arm64 og ble stående på 2.10.2 mens 2.11.0 bare var amd64, er dette steget ditt til redigeringsprogrammet for case-strukturer, utvalg til underdiagram, det ryddige oppsettet, navngitte forbindelser, zoom til 400 prosent, nodesymbolene, innstilleren for panelobjekter og skriveporten for diagrammer: les notatene for 2.11.0 for hva de er. Ingenting skjer ved første oppstart, og ingenting må migreres.

想知道某个值是何时采样的订阅者，现在可以从数据包里直接得到，而不是根据它到达的时间去猜，并且您可以像安装任何其他附加组件一样，通过 CODESYS Installer 安装这个库。

两个发布者，Variant 和 RawData，开启时间戳，每个值都等于 PLC 通过它自己的 OPC UA 服务器报告的值。HotLoop core 的订阅者，无论是这次测试时的主分支，还是 HotLoop core 4.19.4 及其之后的每个版本，都能读取两个发布者，每个读数都以发布者的时间戳作为它的时间。该包可以通过 PackageManagerCLI 安装，示例可以针对它构建。在有两个发布者的 20 ms 任务上，该块平均每个周期增加约 9.6 微秒，这次运行中最长的周期是 81 微秒。

没有运行的内容：任何物理控制器，除 Control for Linux SL 4.22.0.0 之外的任何运行时，实时时钟未设置或不正确的控制器（该块会盖上时钟所显示的时间），在 IDE 自己的 Package Manager 窗口中的该包，多播，丢失并重新获得网络的运行时，以及两小时演示窗口结束时的情形。

不在这个版本中的内容：KeepAlive 和 Delta Frame，每个 NetworkMessage 多于一个 DataSetMessage，WSTRING，每个字段的状态，亚秒级时间戳，消息安全，以及订阅者一侧。固定在 1.0.0 的 PLC 项目仍然可以工作，并且继续发送 1.0.0 的字节。

从 [hotloop.io/hotloop-transmitter/1.1.0/](https://hotloop.io/hotloop-transmitter/1.1.0/HotLoopTransmitter-1.1.0.library) 下载 `HotLoopTransmitter-1.1.0.library`、`.compiled-library` 或 `.package`，用同一文件夹中的 `SHA256SUMS` 校验，并查看[安装页面](https://docs.hotloop.io/transmitter/install/)。

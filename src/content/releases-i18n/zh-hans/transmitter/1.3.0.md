已在使用 1.2.0 的 PLC 项目发送的字节与之前相同,只有一处可见的差异:时间戳现在带有毫秒。其余一切都通过一次调用或一个输入来开启。

安装 `HotLoopTransmitter-1.3.0.library`(或用 CODESYS Installer 打开 `.package`),把项目 Library Manager 中的库版本改为 1.3.0.0,然后编译。HotLoop Alarms 1.0.0.0 原样随附,固定在 1.2.0 的项目继续工作。

从 [hotloop.io/hotloop-transmitter/1.3.0/](https://hotloop.io/hotloop-transmitter/1.3.0/HotLoopTransmitter-1.3.0.library) 下载 `HotLoopTransmitter-1.3.0.library`、`.compiled-library` 或 `.package`,以及 `HotLoopAlarms-1.0.0.0.library` 或其 `.compiled-library`,用同一文件夹中的 `SHA256SUMS` 校验,并参阅[安装页面](https://docs.hotloop.io/transmitter/install/)。

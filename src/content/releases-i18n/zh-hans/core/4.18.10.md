highlights:
  - "四个产品，四个镜像，四个 chart，一个标签。hotloop-iot 和 hotloop-edge 是 ghcr.io 上以及 chart 仓库中的新成员。chart 仓库地址是 https://hotloop.io/hotloop. Gateway 保留 ghcr.io/hotloop-io/hotloop 和 chart hotloop，所以正在运行它的人无需改动任何东西。产品是一次构建，不是一个设置：OPC UA 服务器不是在 IoT 镜像里被关掉了，而是根本不在里面。"
  - "MQTT 发现：把 ESPHome、Zigbee2MQTT、Tasmota 或 Shelly 指向 broker，它就会出现，处于读取状态。在管理员接受并手动启用每个点位之前，它无法控制任何东西。网络发现只监听，除非您列出要探测的网络，否则不发送任何内容。"
  - "历史数据库目标：HotLoop 保存的每个读数也会送到工厂自己的 PostgreSQL、TimescaleDB、SQL Server、InfluxDB 或 MySQL/MariaDB，行相同，质量相同。"
  - "数据库是一个设置：每个产品可选 SQLite、PostgreSQL 或 TimescaleDB，使用同一个二进制文件，所以树莓派不需要 300 MB 的数据库镜像。"
  - "WAN 中断时 Edge 也让工厂保持运行，它的存储转发队列能经受住中断期间的启动、没有复位就断开的链路，以及必须比工厂跑得更快的重放。"
  - "每台设备都跟随 :stable 并自行更新，无法启动的版本会被回滚。迁移只新增，应用拒绝在领先两个版本的模式上启动，所以这种回滚始终是安全的。"
  - "墙面看板和手机上的 UniFi：可缩放的网络地图、WAN 延迟和端口流量的曲线、一个生成常用报警的按钮，以及在 logbook 中显示在所属交换机之下的 UniFi 事件。智能体可以通过 MCP 查询拓扑和控制台的最新事件。"
  - "Edge Relay 可以在线接收推送的配置，无需重启，也不会丢失 Sparkplug 会话，并像 Gateway 一样发现 broker 上的设备。"
  - "许可证变了：四个产品都采用 HotLoop Business Source License 1.1。家庭和实验室使用免费，学校、非营利组织和政府机构使用也免费。"
  - "顺带修复：被发现设备的值可能被它自己尚无值的占位读数覆盖，内置的 MQTT broker 在两个方向上都错误处理了数据包 ID，还在加载中的仪表板可能把人带回他们刚离开的那个。"
breaking:
  - "从 4.17.0 升级请使用 --reset-then-reuse-values 或您的 values 文件。单独的 --reuse-values 能渲染，但会重放 4.17.0 的值，丢掉每一个新的默认值。"
  - "edgePublish.queueMaxBytes 现在默认是 64 MiB，不再无限。超出后最旧的读数会被丢弃并计数。请按您自己的读数速率来定大小，每个读数约 180 字节，或设为 0 以保留旧行为。"
  - "迁移只新增，回到 4.17.0 也能运行，但请先做 pg_dump。"
  - "在 Settings, MQTT 中创建的登录会带上配置文件里的 topic 规则。在 Settings 之外配置的登录不受影响。新增了权限 fleet.update，仅限管理员。"
---

IoT、Edge、Gateway 和 Edge Relay 都从这个标签同步发布。4.18.10 是拆分为四个产品后首个公开发布的版本，取代之前所有的 4.18 标签。不应使用任何名为 4.18.8 的东西。

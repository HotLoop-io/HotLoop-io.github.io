用 `podman pull ghcr.io/hotloop-io/hotloop-cascade:0.1.2` 拉取，或用 `helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 0.1.2` 安装 chart。镜像支持 amd64 和 arm64，标签是 0.1.2、0.1、0、latest 和 stable。

从 0.1.1 升级不需要做任何事。对 0.1.2 执行 `helm upgrade`，或者让 `:stable` 滚动更新 Quadlet 单元。您的密钥和工作流都留在原处。

标签运行是 ghcr.io 第一次见到这里面的任何东西。

如果您在工厂里运行 Cascade,这个版本让智能体可以从外部操作它,也让人可以在编辑器里完成以前需要 curl 的事。引擎、工作流文件格式和 REST API 与 1.0.2 相同。

有些路由特意不做成工具:创建 API 密钥、SCIM 令牌、密钥提供方和日志目的地需要有人登录,因为能创建密钥的密钥就是一把会自我延续的泄露密钥。`docs/MCP.md` 列出了每个工具及其背后的权限。

使用 `helm upgrade` 升级到 1.1.0,或让 `:stable` 滚动更新 Quadlet 单元。数据库没有任何变化,所以退回 1.0.2 是安全的。回滚无法撤销的是智能体已经做过的事。每次更新之前先备份,仍然是正确的习惯。

用 `podman pull ghcr.io/hotloop-io/hotloop-cascade:0.1.1` 拉取，或用 `helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 0.1.1` 安装 chart。镜像支持 amd64 和 arm64，标签是 0.1.1、0.1、0、latest 和 stable。这个版本的镜像仓库是私有的，所以需要先以 root 身份执行 `podman login ghcr.io`。镜像和 chart 从 0.1.2 起公开，无需登录即可拉取。

曾经有过一个 0.1.0 标签，它从未发布过任何东西。那个测试是通过在旧 pod 还在停止的时候列出 pod 来检查升级的，而一台安静的笔记本永远不会暴露这个问题。

迁移只会向前。回滚会把旧镜像放回去，但不会撤销您数据库的迁移，所以在打开更新之前请先备份。如果丢失了用来封存已存储凭据的密钥，所有已存储的凭据都将无法读取，所以请把一份副本保存在不是这台机器的地方。还没有的：SAML、LDAP、SCIM、环境、带租约的高可用调度器、更多连接器和 AI 步骤。那是 0.2.0 及以后。

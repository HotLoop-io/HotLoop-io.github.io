用 `podman pull ghcr.io/hotloop-io/hotloop-cascade:1.0.0` 拉取，或用 `helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 1.0.0` 安装。镜像支持 amd64 和 arm64。

我把它叫作 1.0.0，是因为编辑器是我在把自己的名字写在这个数字下面之前最后想要的一块。它目前还不是对工作流文件格式或 API 的承诺，路线图写明了还没有做的东西：Git 源码管理和环境、更多连接器，以及 AI 步骤。0.1.2 里的一切仍然照常工作。升级前请先备份，因为回滚只是把旧版本放回去，并不会撤销数据库的变更。

变量不是密钥：任何能读取一个项目的人都能读取它的变量。外部密钥需要允许的路径，没有任何路径的提供方会被有意拒绝。SCIM 永远不会向提供方显示实例所有者，DELETE 会停用一个账户并把它隐藏。SAML、LDAP 和 OIDC 的设置在启动时从环境中读取，所以登录界面只显示哪些已开启，不会修改它们，登录页面本身仍然是之前那个朴素的页面。

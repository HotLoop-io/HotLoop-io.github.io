HotLoop Flow 2.14.1 就是加上 arm64 镜像的 2.14.0，没有别的。2.14.0 只发布了 amd64，为的是先进入生产并被标为稳定版，这是同时构建两者的那个小后续版本。代码、chart、设置和您的 flow 都没有变化。

## 变更内容

- 镜像为 linux/amd64 和 linux/arm64 构建。`2.14.1`、`2.14` 和 `2` 标签都包含这两者。
- README 和安装页面写明 2.14.1，并同时说明 amd64 和 arm64。

## 升级

对 2.14.1 的镜像和 chart 执行一次普通的 `helm upgrade`，或者在您的 Quadlet 单元里换成新标签。如果您用的是 arm64，并且在 2.14.0 仅支持 amd64 期间一直停在 2.13.1，这就是您升到其余 MCP 工具和批量排空的机会：请阅读 2.14.0 的说明了解它们是什么。首次启动时什么都不会发生，也没有需要迁移的内容。

HotLoop Flow 2.17.2 把 2.17.1 带到 arm64。现在一个镜像同时覆盖您的 x86 设备和 arm64 设备，例如 64 位 Raspberry Pi或 ARM 边缘网关。代码、chart、设置和您的流程都没有变化。

## 变更内容

- 镜像为 linux/amd64 和 linux/arm64 构建。标签 `2.17.2`、`2.17` 和 `2` 都同时包含两者。
- README 和安装页面使用 2.17.2，并说明支持 amd64 和 arm64。

## 升级

直接对 2.17.2 镜像和 chart 执行 `helm upgrade`，或在 Quadlet 单元中使用新标签。chart 的镜像标签取自它自己的版本，所以安装了 2.17.1 chart 的 arm64 设备要升级到 2.17.2 才能拿到它的镜像。如果您使用 arm64 并一直停留在 2.16.1，这就是您的升级步骤；请阅读 2.17.1 的说明了解此后的全部新内容。首次启动时不会发生任何事，也无需迁移。

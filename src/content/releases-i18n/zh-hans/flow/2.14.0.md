HotLoop Flow 2.14.0 让智能体通过 MCP 触达 Flow 的其余部分，并在故障之后按批排空积压，而不是一次一条消息。

## 变更内容

- Flow 自己的 MCP 工具只覆盖 flow 本身，不涉及周边。现在多了 22 个，共 29 个，`docs/MCP.md` 列出每个工具的路由和权限。登录、每个人自己的第二因素和实时编辑器套接字不是工具，页面里说明了原因。
- 通往接受批量的节点的持久连线，一次领取最多 256 条消息。如果一批没有被接受，第一条失败之前的消息标记为已完成，那一条单独重试，其余的重新发送，所以不会丢失，也不会乱序。投递仍然是至少一次，进程被终止时正在传输的消息可能再来一次。
- LICENSE 文件中的 Licensed Work 一行只写 HotLoop Flow。

## 升级

对 2.14.0 的镜像和 chart 执行一次普通的 `helm upgrade`，或者在您的 Quadlet 单元里换成新标签。首次启动时什么都不会发生，也没有需要迁移的内容。这个版本只有 amd64：arm64 机器在 2.14.1 之前停留在 2.13.1。

  - "图标默认是 chart 自己的图标。它由 GitHub raw 提供，后者会发送 Access-Control-Allow-Origin: *，所以仪表板的 crossorigin 图片确实能画出来。要使用您自己的图标，请设置 embernet.appIcon，并确保它所在的位置也发送这个头，否则磁贴是空白的。"
  - "embernet.ai/app-name 标签现在是 chart 的名称，而不是 release 的名称。仪表板会把它写在它自己部署的所有内容上，用它来匹配目录图标，Ignition 网关列表之类的功能也以它为依据。"
  - "pod 属于哪个实例，仍然记录在 app.kubernetes.io/instance 和 Service 名称里，没有任何 selector 改变，所以原地升级是安全的。"

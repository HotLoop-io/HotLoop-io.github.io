Este es el primer chart del índice en hotloop.io/hotloop-codesys/, publicado el 2026-11-05. Necesita HotLoop 4.19.4, que ya está publicado, y queda sustituido por 0.3.1 ese mismo día: 0.3.1 es la que hay que instalar.

Contra qué se ejecutó: un runtime CODESYS Control for Linux SL 4.22.0.0 en un contenedor, ejecutando el propio programa de laboratorio de HotLoop, con una imagen de HotLoop Edge construida desde la rama principal de HotLoop. El dispositivo, sus tags, la alarma y la pantalla aparecieron sin ningún paso manual, cada valor se leyó bien y se movió, los pods volvieron tras borrar un pod, y la instalación se leyó como mala con el motivo "the PLC's runtime is not answering" durante un reinicio del runtime y volvió sola unos 88 segundos después.

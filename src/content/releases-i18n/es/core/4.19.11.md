No hay migraciones, y el único cambio de la API es una ruta nueva.

Esta compilación es solo amd64, y la siguiente versión es un pequeño aumento de versión que compila las imágenes arm. Mientras tanto, `stable` conserva las imágenes arm que tiene. 4.19.10 es la última compilación multiarquitectura anterior a esta, y las notas de 4.19.8 enumeran todo lo que cambió desde la anterior a esa.

Las pruebas también cambiaron: una que esperaba la lectura equivocada bajo carga ahora espera lo que comprueba, el laboratorio de pruebas vuelve a iniciar el emulador de UniFi cuando este termina, y el Redpanda del laboratorio tiene abierta su API de administración.

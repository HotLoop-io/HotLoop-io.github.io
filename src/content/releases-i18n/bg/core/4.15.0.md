Тествано срещу собствения OPC UA сървър на Gateway и opc-plc на Microsoft. Aes256_Sha256_RsaPss се провали срещу opc-plc, така че драйверът го използва само когато устройство го поиска по име. В тази версия API все още връщаше паролите за MQTT, HTTP и MTConnect в явен вид. 4.15.1 го поправи.

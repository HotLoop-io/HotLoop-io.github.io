Nothing here can be installed today. The chart index at hotloop.io/hotloop-codesys/ answers and lists no chart, the provisioner image is public but no chart installs it yet, and HotLoop 4.19.0, which it needs, has not shipped.

What it was run against: a CODESYS Control for Linux SL 4.22.0.0 runtime in a container, running HotLoop's own lab program, with a HotLoop Edge image built from HotLoop's main branch. The device, its tags, the alarm, and the screen appeared with no hand step, every value read good and moved, the pods came back after a pod delete, and the install read bad with the reason "the PLC's runtime is not answering" through a runtime restart and came back by itself about 88 seconds later.

What it was not run against: an install from the real App Store page, a physical controller, k3s v1.35.7 (the lab is v1.36), a node that really lost its link to the control plane, a download from the CODESYS IDE while the runtime stays up, and a runtime on the host's own network beside the HotLoop pod on one node.

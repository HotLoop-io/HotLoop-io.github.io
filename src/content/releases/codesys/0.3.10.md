0.3.10 is the one to install, and it carries everything 0.3.9 added. It was installed from the index on a real cluster with a profile of one OPC UA PubSub listener and two screens: the provisioner made the device, its two tags and both screens with no hand step, the device read connected, and the HotLoop log had no warnings or errors. Deleting both pods brought them back by themselves with the device still configured, an upgrade from 0.3.8 kept the device and its tags, and an install with no profile gave HotLoop alone.

The 4.24.0 image is built for amd64, so on an arm64 node pin HotLoop to an amd64 one.

0.3.1 is in the index at hotloop.io/hotloop-codesys/, published 2026-11-05, and the provisioner image it runs, ghcr.io/hotloop-io/hotloop-provision at 0.3.0, pulls with no login. The consequence: install this one, not 0.3.0, because a release name of your own choosing now works the way you would expect.

It installs from the EmberCORE App Store, where it is listed for EmberNet staff, who put it on a tenant, or with Helm from the index. The chart renders from the live index with Helm (checked 2026-11-14 with the provisioner switched off). It has not been run from the real App Store page, on a physical controller, or on a node that lost its link to the control plane.

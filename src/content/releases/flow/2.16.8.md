HotLoop Flow 2.16.8 makes a flow you bring over from Node-RED behave the way it did there, and makes sure one odd value can never take your plant's Flow down. Nothing in your flows, settings or chart changes.

## What changed

- **A value that holds itself no longer stops Flow.** Node-RED lets a change node write a list into itself and carries on. Flow now cuts the loop where it turns back on itself, that one node reports it like any other node error, and every other flow keeps running. Function nodes that return, send or set such a value are covered too.
- **Function nodes speak modern JavaScript.** `await`, a returned promise, a Setup promise that holds the first message, and `node.linkcall` all work.
- **Node-RED's own example flows give Node-RED's output.** All 62 recorded examples match, including switch part counts, csv types and columns, and reset and flush on a delay.
- **FlowLab reads a LabVIEW VI's block diagram.** Anything FlowLab has no equivalent for stays visible as a named node.

## Upgrade

A plain `helm upgrade` to the 2.16.8 image and chart, or the new tag in your Quadlet unit. Nothing needs migrating.

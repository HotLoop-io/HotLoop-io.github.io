It switched authentication off, the startup check refused any config with authentication off, and the refusal told you to set the variable you had just set. From 0.1.0 through 2.0.4. It works now, and only from the environment: auth.enabled false in the config file still refuses to start on its own, because a config file is where a copy-paste lands."
  - "Running without a login is loud about it. Every boot logs a warning, and the editor shows a NO LOGIN badge where Sign out would be, so whoever opens it next knows the door is open. The credential secret still needs its own opt-out."
  - "The editor asks the runtime whether it needs a login instead of assuming. Before, even a runtime that had started with authentication off would have landed you on a login screen with no users behind it, and the live event stream refused to connect without a token."
  - "The chart no longer adds NET_RAW and NET_ADMIN when discovery is on. The scan node only makes TCP connections, so those were privilege for nothing. Every render keeps all capabilities dropped, and CI fails if one comes back."

The config package had no tests at all, which is how the first bug lived this long. It has them now, and four of them fail on the old check. Both ways, authentication on and off, were driven end to end in a browser against the built binary before this was tagged.

HotLoop Flow 2.13.1 is 2.13.0 with the arm64 image added, and nothing else. 2.13.0 shipped amd64 only so it could get to production and read stable first, and it did: a plant has run it clean. This is the one small bump that builds both. There is no change to the code, the chart, the settings or your flows.

## What changed

- The image is built for linux/amd64 and linux/arm64. The `2.13.1`, `2.13` and `2` tags hold both.
- The README and the install pages name 2.13.1 and say amd64 and arm64.

## Upgrade

A plain `helm upgrade` to the 2.13.1 image and chart, or the new tag in your Quadlet unit. If you are on arm64 and stayed on 2.12.1 while 2.13.0 was amd64 only, this is your move to the notification nodes, Kafka out, the intensity chart, serial flow control, diagram tests and a deploy that keeps a run that did not change: read the 2.13.0 notes for what they are. Nothing happens on first start and nothing needs migrating.

Use 2.10.2. There is no change to the code, the chart, the settings or your flows.

## What changed

- The image is built for linux/amd64 and linux/arm64. The `2.10.2`, `2.10` and `2` tags hold both.
- The README and the install pages name 2.10.2.

## Upgrade

A plain `helm upgrade` to the 2.10.2 image and chart, or the new tag in your Quadlet unit. From 2.10.0 nothing changes on amd64. If you are on arm64 and still on 2.9.1, this is your move to everything in the 2.10.0 notes: FlowLab's instruments, case structure, waveforms, shared record types, sub-diagrams and log rotation, the MCP tools that list, read, deploy and roll back flows, the heap held to the container's memory limit, and the fix that stops a durable MQTT output sending a message twice after a reconnect. Nothing happens on first start and nothing needs migrating. If anything pinned 2.10.1, move it to 2.10.2: that image does not exist.

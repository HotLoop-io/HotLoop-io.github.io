2.7.0 shipped amd64 only so it could get to production and read stable first, and this is the one small bump that builds both. A plain `helm upgrade` to the 2.7.1 image and chart, or the new tag in your Quadlet unit. Nothing happens on first start and nothing needs migrating.

What isn't proven: the arm64 image is built under emulation on the runner, and it starts and reports its version in the release run. It has not been run on an arm64 box for this release.

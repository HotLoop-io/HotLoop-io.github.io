If you wire plants for a living, this is the release where the editor stops looking like it came from a different company. Same flows, same engine, same shortcuts. The difference is a screen that fits what you do all day: put the thing on the canvas, deploy it, and watch it run.

It is a plain image bump from 2.4.0. There is nothing to migrate and no new settings. Reload the editor tab once after the pod restarts so your browser stops showing the old one.

One thing is slower, and I would rather say so. The page is blank for a moment until the editor has loaded, where the old one painted its frame first. With the browser cache off, the sign-in form took about 12 ms longer on one machine, about 100 ms longer over a 20 Mbps link, and about half a second longer over a 1.6 Mbps link with 150 ms of latency. On a plant LAN it is a few milliseconds. On a bad link you will see a white page for a beat.

I have not opened this editor in Firefox or Safari, on a tablet, on a plant HMI screen, or inside the live EmberCORE dashboard frame. The browser tests and the screenshots run in Chrome. The full notes are on [the GitHub release](https://github.com/HotLoop-io/hotloop-flow/releases/tag/v2.5.0).

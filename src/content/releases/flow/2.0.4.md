  - "The embernet.ai/app-name label is the chart name now, not the release name. That is what the dashboard writes on everything it deploys itself, what it matches catalog icons on, and what features like the Ignition gateway list key on."
  - "Which instance a pod belongs to is still in app.kubernetes.io/instance and the Service name, and no selector changed, so upgrading in place is fine."

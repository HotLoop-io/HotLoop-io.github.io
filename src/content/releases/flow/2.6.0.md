If you run durable wires on a plant line, this release gives you a way to know when one has stopped delivering. Nothing about how your flows run changes.

It is a plain image bump from 2.5.0. There is nothing to migrate and no new settings; the counter is on, and there is no switch.

The counter is tested by making the fault by hand, and the test fails with the pump's check removed. It has never fired on a real wire, because I have never seen the real fault, and the cause of the drop-oldest failure is still not found. If it ever fires on your line, the log line is what I need. The full notes are on [the GitHub release](https://github.com/HotLoop-io/hotloop-flow/releases/tag/v2.6.0).

Nothing in this release changes how a flow file is read or written, so a `flows.json` that ran on 2.0.5 runs on 2.1.0. Upgrading is an image bump. The first start creates `sessions.json`, `audit.log` and a `deployments` directory under the data directory, and everyone signs in once because sessions used to live in memory.

Lockout is on by default: five failures for one account from one address, or twenty from one address, locks it for fifteen minutes. `auth.lockout` changes the numbers.

It has never run on a real plant floor. The tests, the race detector, a real Mosquitto and the browser tests are all behind it, and none of that is a plant. The full notes, with every new setting, are on [the GitHub release](https://github.com/HotLoop-io/hotloop-flow/releases/tag/v2.1.0).

A subscriber that wants to know when a value was sampled now gets it from the packet instead of guessing from when it arrived, and you can install the library through the CODESYS Installer like any other add-on.

What was run, on The Beast against CODESYS Control for Linux SL 4.22.0.0 in a container: the library and the example build with 0 errors and 0 warnings in CODESYS 3.5.22.30. Two publishers, Variant and RawData, with timestamps on, and every value equals what the PLC reports over its own OPC UA server. Every message has both timestamps, the same instant, never going backwards, and over an 11 second capture the stamp moved 11 seconds. open62541 1.4.9 reads both timestamps of all 113 messages of each writer. HotLoop core's subscriber, from its main branch when this was run and in HotLoop core 4.19.4 and every release after it, reads both publishers with every reading carrying the publisher's timestamp as its time. The package installs through PackageManagerCLI and the example builds against it. On a 20 ms task with two publishers the block adds about 9.6 microseconds per cycle on average, and the longest cycle in the run was 81 microseconds.

What was not run: any physical controller, any runtime but Control for Linux SL 4.22.0.0, a controller whose real-time clock is unset or wrong (the block would stamp what the clock says), the package in the IDE's own Package Manager window, multicast, a runtime that loses and regains its network, and the end of the two hour demo window.

Not in this release: KeepAlive and Delta Frames, more than one DataSetMessage per NetworkMessage, WSTRING, a per-field status, sub-second timestamps, message security, and the subscriber side. A PLC project pinned to 1.0.0 keeps working and keeps sending the 1.0.0 bytes.

Download `HotLoopTransmitter-1.1.0.library`, the `.compiled-library` or the `.package` from [hotloop.io/hotloop-transmitter/1.1.0/](https://hotloop.io/hotloop-transmitter/1.1.0/HotLoopTransmitter-1.1.0.library), check them against `SHA256SUMS` in the same folder, and see the [install page](https://docs.hotloop.io/transmitter/install/).

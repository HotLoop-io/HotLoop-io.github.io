A PLC project that already uses 1.2.0 sends the same bytes as before, with one visible difference: the timestamp now has milliseconds. Everything else is something you switch on with a call or an input.

Install `HotLoopTransmitter-1.3.0.library` (or open the `.package` with the CODESYS Installer), change the library version in your project's Library Manager to 1.3.0.0, and compile. HotLoop Alarms 1.0.0.0 comes with it unchanged, and a project pinned to 1.2.0 keeps working.

Download `HotLoopTransmitter-1.3.0.library`, the `.compiled-library` or the `.package`, and `HotLoopAlarms-1.0.0.0.library` or its `.compiled-library`, from [hotloop.io/hotloop-transmitter/1.3.0/](https://hotloop.io/hotloop-transmitter/1.3.0/HotLoopTransmitter-1.3.0.library), check them against `SHA256SUMS` in the same folder, and see the [install page](https://docs.hotloop.io/transmitter/install/).

4.23.3 puts a screen's logic where an operator can see it. Any symbol on any screen can be shown by a rule and painted by a rule, and a CODESYS screen keeps its hiding and its alarm colors when it comes into HotLoop.

## What changed

- **A symbol can be shown and painted by rules.** `show` draws a symbol only while a rule on a tag holds. `colors` is up to four rules, each with a tone, and the first one that holds paints the symbol. A rule is a tag and a comparison: on, off, equal, not equal, greater or less. The builder's symbols form has both, and a screen file lists and moves the rules' tags with the rest.
- **The CODESYS screen import carries Invisible and Toggle color.** An element's Invisible variable becomes a show rule and its Toggle color variable becomes a color rule, and the import says what it could not carry, with the variable.
- **The backup list does not fail while a backup is pruned.** A backup that went is left out of the list.

## Upgrade

A plain `helm upgrade`. No migration and no new secret. A symbol with neither rule is drawn as before.

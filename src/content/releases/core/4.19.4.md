4.19.0, 4.19.1, 4.19.2 and 4.19.3 were tagged and never published, so nothing named any of them exists and `stable` never moved to one. This is the first release with everything their notes list. Two of them died in the Test job on bugs in the product, a discovery listener that said it was up before it could hear and a process that stopped the next run of a script with its own stop, and both are fixed here.

The first thing to read is what changes on a running plant: agents write now, and a scaled tag takes the number you meant. [Upgrading from 4.18.11](https://docs.hotloop.io/gateway/upgrading/#upgrading-from-41811) has both, with the command.

This build is amd64 only, so it could reach production and read stable before the arm images were built. [4.19.5](/releases/core/#core-4.19.5) is the build that adds them, and it is the same code.

What isn't proven: CODESYS has not been run on a physical controller, OPC UA PubSub has met open62541 and nothing from CODESYS, Siemens or Beckhoff, and the Kafka stream has met Apache Kafka 4.4.0 and Redpanda 26.2.6 and not Confluent Cloud, Amazon MSK or Azure Event Hubs. Everything the 4.18.11 notes list as unproven still is.

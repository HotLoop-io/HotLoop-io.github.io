Read 4.19.8's notes for everything that changed since the last multi-arch release. This release changes none of it.

4.19.9 was tagged for this build and never published. Its release run failed in the Test job before anything went out, so `stable` kept listing the 4.19.8 amd64 images beside the older arm ones until this one. Nothing named 4.19.9 exists.

What failed was the test lab, not HotLoop. The lab starts a UniFi controller and an emulator of four switches that adopt themselves into it. The emulator looks the controller up by name once, when it starts, and exits if that one lookup gets no answer. On the runner the name server missed it, the emulator exited, nothing started it again, and the lab waited fifteen minutes for four devices that were never going to adopt. The lab now starts the emulator again whenever it has exited, for up to two minutes, before it waits on the devices.

It is the last build of every architecture so far.

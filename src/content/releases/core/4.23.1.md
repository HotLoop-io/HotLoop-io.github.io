4.23.1 is the release 4.23.0 was meant to be. The 4.23.0 tag died in its test job, on an OPC UA login that got ten seconds on a starved runner, before any image, chart or release existed, so nothing was ever published under it. This one carries all of it.

## What changed

- **A weather station is one entity,** built from the tags a roof station already publishes. A sensor it was not given has no row, and one that stopped answering reads Unavailable, never zero.
- **Energy meters.** A meter is a tag read as a quantity used, kept in 15 minute buckets, so a restart loses nothing and a shift, a day or a month is a sum. A tariff prices each bucket when it is made, and the cost of a unit made comes from a production meter. There is an Energy screen, the API and MCP tools.
- **Thirteen more languages** beside English, picked in the top bar or on the sign-in card.
- **A dashboard exports to a file and imports into another install.** A customer's screens are theirs and never part of the product. Export and Import are buttons on the Dashboards screen, and the MCP server has both.
- **The first commands to a UniFi console:** a device's locate LED, a device restart, a switch port's PoE power cycle, a wireless network on or off, a watched client blocked, and a port's PoE mode. Every one goes through the write gate and does nothing until somebody arms that tag. The console account has to be a local Administrator, and HotLoop says so when a View Only account is refused. A port that carries the network is never cycled.
- **The OPC UA server answers HistoryRead,** raw and processed, and PubSub can send delta frames as an option that is off by default.
- **The database upgrade unit of a Quadlet install skips itself** when there is nothing to upgrade, and the charts keep their credentials Secret on uninstall, so a reinstall under the same name no longer generates a password the kept database refuses.

## Migrations and API

Two migrations, `0028_unifi_port_cycles` and `0029_energy`, and both only add. A backup taken on 4.22.1 restores here, and one taken here does not restore onto an older release. New routes cover energy meters, summaries and series, and dashboard export and import. Two new permissions, `energy.read` for every role and `energy.write` for an admin.

## Upgrade

A plain `helm upgrade`. The migrations run at first start and nothing is turned on that was off. This release builds the amd64 image, and the multi-arch build follows as the next version.

## What isn't proven

- The UniFi commands were proven against the lab's real UniFi Network Application with emulated switches, and one power cycle of an access point on the house network. The rest have not been run against a real console.
- Delta frames are read back by HotLoop's own decoder, and open62541's subscriber discards them, which is why the option is off.
- Weather and energy ran against recordings, a Modbus rig and simulated counters, not a real roof station or a plant's meters.
- No native speaker has reviewed the thirteen new language catalogs.

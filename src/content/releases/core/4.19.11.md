There are no migrations, and the one API change is a new route.

This build is amd64 only, and the next release is one small version bump that builds the arm images. `stable` keeps the arm images it holds in the meantime. 4.19.10 is the last multi-arch build before it, and 4.19.8's notes list everything that changed since the one before that.

The tests changed too: one that waited for the wrong reading under load now waits for what it asserts, the test lab starts the UniFi emulator again when it exits, and the lab's Redpanda has its admin API open.

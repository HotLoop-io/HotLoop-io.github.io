highlights:
  - "A client can sign in to the OPC UA server with an X.509 certificate. An admin attaches the client's public certificate to a HotLoop user, and a client holding the private key signs in as that user with that user's permissions. Revoking a certificate ends its live session within ten seconds."
  - "Passwords of 65 to 72 bytes now sign in over OPC UA. They always worked in the web UI, and the library the server is built on refused any password over 64 bytes."
  - "The deprecated security policies Basic128Rsa15 and Basic256 are off by default, on new installs and on upgrades. A legacy client connects again once an admin switches the legacy policies back on."
  - "The CODESYS alarm import reads an Outside range alarm, which comes across as two alarms at the lower and upper limits."
  - "There are five new MCP tools, 133 in all."
breaking:
  - "A client of the OPC UA server that speaks only Basic256 or Basic128Rsa15 stops connecting after the upgrade until you move it to Basic256Sha256 or set the legacy switch."

A plain `helm upgrade` or the Quadlet auto-update takes it.

A CA that vouches for client certificates is not built, only the registry.

This build is amd64 only, and `stable` keeps the arm images it holds. The next release is one small version bump that builds the arm images.

4.23.2 closes the loop between a CODESYS PLC, HotLoop and the EmberNet dashboard, and it sweeps the test suite's slow-node failures, each one a real wait or race fixed.

## What changed

- **A CODESYS visualization imports as a screen.** Export it from the IDE as the native export file, and Import on the Dashboards screen reads it. A button or setpoint on a tag that is not writable is refused, the same as a build.
- **Box health for the EmberNet dashboard.** A device named for the Kubernetes node publishes the box's CPU, memory, disk and data volume use, and the real-time jitter of three cores when an agent writes the file for it. The OPC UA server serves their history.
- **A login that can read and nothing else.** The chart makes one for the dashboard at the first install and never rotates it on upgrade. The dashboard's certificate is trusted from a Secret, added within 30 seconds and removed when it leaves, and the server still takes only Basic256Sha256 SignAndEncrypt with no anonymous sessions.
- **Energy gets a demand charge and shifts.** A meter takes a price for one kilowatt of its highest quarter hour in a window, and the summary shows the peak, when it started and how much of that quarter hour was read. A cost per unit made reads none, with a reason, when nothing has been counted, not free.
- **Fixes the suite found:** the energy engine no longer reads a meter while it is being deleted, a backup's manifest is renamed into place so a listing never sees half a file, and the historian's catch-up waits until it has written everything up to a mark.

## Box health is on by default

The chart mounts the host's root and its `/proc` read-only and adds no privilege. A cluster that enforces the restricted Pod Security profile refuses a host path, and there box health is switched off, or its host mount is, and the box's disk and CPU read bad and say what to mount.

## Upgrade

One migration, `0030_energy_demand`, which only adds a column with a default of 0. A plain `helm upgrade` runs it at first start. This release builds the amd64 image, and the multi-arch build follows as the next version.

## What isn't proven

- The CODESYS import was proven against one visualization from the lab's IDE, and a screen from another project may list more elements it could not place.
- Box health ran on the lab's nodes, and the jitter tags need an agent that writes the file, which this release does not install.
- The read-only login and the certificate trust were proven against HotLoop's own client. The EmberNet dashboard's side is its own release.
- Demand charges were checked against recorded readings, not a utility's bill.

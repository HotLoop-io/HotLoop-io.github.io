4.24.2 adds three kinds of device, sends OPC UA passwords of any length the way the specification asks, and fixes two edge problems: a forward queue that never emptied behind a slow link, and a default Edge install that did not start.

## What changed

- **Shelly, any generation.** Gen2 and later over RPC with a live websocket, so a change and a button press arrive the moment they happen, and Gen1 over its own HTTP interface. A button press is filed in the logbook under the device.
- **ONVIF cameras.** Find cameras on the network (WS-Discovery), read each one's device information, every media profile's stream and snapshot address (Media and Media2), pan, tilt and zoom, and the camera's own events as tags and logbook lines. A profile's current picture is one route away.
- **Arduinos over Firmata.** USB serial or TCP, with digital and analog pins, PWM, servos and I2C devices as tags.
- **OPC UA passwords of any length.** Passwords over 64 bytes now go over OPC UA the way the specification asks (RsaEncryptedSecret, part 4, 7.40.4), from the client and to the server, and older servers still sign in. Proven against the OPC Foundation's own stack.
- **A slow link no longer pins the node to its disk.** The pass that takes the last of the disk now sends what comes in behind it from memory, so a forward queue behind a slow link empties and the node leaves the disk instead of fsyncing on every poll.
- **A default install of HotLoop Edge starts.** The pod no longer reads alarm channel credentials from a Secret that does not exist; each is sent only when its credential is set, and a chart with a destination set renders as before.

## Upgrade

A plain `helm upgrade`. No migration and no new secret. This release builds the amd64 image, and the arm images follow in the next version.

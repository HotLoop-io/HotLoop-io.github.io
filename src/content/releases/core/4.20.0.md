There are no migrations, and a plain `helm upgrade` or the Quadlet auto-update takes it. The previous release, 4.19.11, is the last one whose default screens were the old ones, and a rollback to it is safe because nothing in the database changed.

This build is amd64 only, and the next release is one small version bump that builds the arm images. `stable` keeps the arm images it holds in the meantime.

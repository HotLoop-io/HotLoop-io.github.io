1.4.1 fixes one thing on the Settings page. The engine, the workflow file format, the REST API, the MCP server and every other screen are what 1.4.0 has.

## What changed

- **The Settings page keeps what you changed.** Every Save is answered with the settings as the server has them. A field you edited between pressing Save and the answer coming back now keeps your edit, instead of snapping back to the value you had just left.

## Upgrade

No migrations. `helm upgrade` to 1.4.1, or let `:stable` roll the Quadlet units.

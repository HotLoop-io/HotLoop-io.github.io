If you run Cascade on an arm64 box, this is the release that brings it back to the current version. Everything else is what 1.1.0 has: the MCP server, and the credentials, projects, users, audit log, settings and account screens.

Upgrade with `helm upgrade` to 1.1.1, or let `:stable` roll the Quadlet units. Nothing in the database changes, so putting 1.1.0 or 1.0.2 back is safe.

If you run Cascade on an arm64 box, this is the release that brings it up to 1.3.0 with the editor in fourteen languages. Everything else is what 1.3.0 has.

Upgrade with `helm upgrade` to 1.3.1, or let `:stable` roll the Quadlet units. Nothing in the database changes, so putting 1.3.0 or 1.2.1 back is safe.

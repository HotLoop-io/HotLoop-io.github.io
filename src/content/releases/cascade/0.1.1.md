Pull it with `podman pull ghcr.io/hotloop-io/hotloop-cascade:0.1.1`, or install the chart with `helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 0.1.1`. The image is amd64 and arm64, and the tags are 0.1.1, 0.1, 0, latest and stable. The registry was private for this release, so it wanted a `podman login ghcr.io` as root first. The image and chart are public from 0.1.2 on and pull with no login.

There was a 0.1.0 tag and it never published anything. Its chart test failed on a hosted runner and I canceled the run, so nothing reached the registry, and a tag stays where it is. 0.1.1 is the same code with the test fixed. It checked the upgrade by listing pods while the old ones were still stopping, which a quiet laptop never shows.

Migrations only go forward. A rollback puts the old image back and does not un-migrate your database, so take a backup before you turn updates on. Lose the key that seals stored credentials and every stored credential is unreadable, so keep a copy somewhere that isn't the box. Not here yet: SAML, LDAP, SCIM, environments, the HA scheduler with leases, more connectors and AI steps. That is 0.2.0 and on.

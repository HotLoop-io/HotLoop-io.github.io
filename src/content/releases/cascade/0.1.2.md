Pull it with `podman pull ghcr.io/hotloop-io/hotloop-cascade:0.1.2`, or install the chart with `helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 0.1.2`. The image is amd64 and arm64, and the tags are 0.1.2, 0.1, 0, latest and stable.

Upgrading from 0.1.1 means nothing to do. Run `helm upgrade` to 0.1.2, or let `:stable` roll the Quadlet units. Your key and your workflows stay where they were.

What isn't proven: the workflows on a real GitHub runner. I ran the workflow's own steps under Podman 4.9.3, the version the runner ships, on a box cut down to two CPUs, 7 GB of RAM and a runner-sized disk, with a local registry that needed a login. The tag run was the first time ghcr.io saw any of it.

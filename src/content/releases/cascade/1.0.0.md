Pull it with `podman pull ghcr.io/hotloop-io/hotloop-cascade:1.0.0`, or `helm install cascade oci://ghcr.io/hotloop-io/charts/hotloop-cascade --version 1.0.0`. The image is amd64 and arm64.

I'm calling it 1.0.0 because the editor was the last piece I wanted before I put my name under the number. It is not a promise about the workflow file format or the API yet, and the roadmap says what is still not built: Git source control and environments, more connectors, and AI steps. Everything in 0.1.2 works the way it did.

Variables are not secrets: anyone who can read a project reads its variables. External secrets need allowed paths, and a provider with none is refused on purpose. SCIM never shows the instance owner to a provider, and a DELETE turns an account off and hides it. SAML, LDAP and OIDC settings are read from the environment at start, so the sign-in screen shows what is on and does not change it, and the sign-in page itself is still the plain one from before.

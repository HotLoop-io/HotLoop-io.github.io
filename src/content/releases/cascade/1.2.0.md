If you run agents against Cascade, this is the release that leaves nothing a key may do without a tool. Everything else is what 1.1.1 has: the editor, the MCP server, and the screens.

Upgrade with `helm upgrade` to 1.2.0, or let `:stable` roll the Quadlet units. Nothing in the database changes, so putting 1.1.1 back is safe. What a rollback can't undo is what an agent already did.

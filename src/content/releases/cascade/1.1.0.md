If you run Cascade in a plant, this is the release that lets an agent work it from outside and lets a person do from the editor what used to take curl. The engine, the workflow file format and the REST API are what they were in 1.0.2.

Some routes are not tools on purpose: making API keys, SCIM tokens, secret providers and log destinations want a person signed in, because a key that could make keys is a leaked key that keeps itself alive. `docs/MCP.md` lists every tool and the permission behind it.

Upgrade with `helm upgrade` to 1.1.0, or let `:stable` roll the Quadlet units. Nothing in the database changes, so putting 1.0.2 back is safe. What a rollback can't undo is what an agent already did. A backup before any update is still the right habit.

What isn't proven: the Quadlet units were not tried on a real Podman host for this release, and they are unchanged from 1.0.2.

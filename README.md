# hotloop.io

Source for HotLoop's marketing site, published via GitHub Pages at [hotloop.io](https://hotloop.io).

Plain static HTML and CSS, no build step. Edit `index.html` and push to `main` to deploy.

See [`HotLoop-io/HotLoop-io`](https://github.com/HotLoop-io/HotLoop-io) for the org overview and canonical LICENSE, and [`HotLoop-io/docs`](https://github.com/HotLoop-io/docs) for docs.hotloop.io.

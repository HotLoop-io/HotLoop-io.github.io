# hotloop.io

Source for HotLoop's marketing site, published via GitHub Pages at [hotloop.io](https://hotloop.io).

Plain static HTML and CSS, no build step. Edit `index.html` and push to `main` to deploy.

This repo is part of the HotLoop-io org. See [github.com/HotLoop-io](https://github.com/HotLoop-io) for the full picture, [`HotLoop-io/HotLoop-io`](https://github.com/HotLoop-io/HotLoop-io) for the canonical LICENSE, and [`HotLoop-io/docs`](https://github.com/HotLoop-io/docs) for docs.hotloop.io.
